> 让 AI 助手像一位总指挥（Orchestrator）一样为你工作：听懂意图、拆解任务、派出专长各异的子代理、盯着进度直到真正完成。

Weir 是 DeepSeek Harness 的一款 agent 预设（preset）。安装后，你会在预设选择器中看到 **Weir**——选中它，助手立刻获得一整套为「认真做完一件事」而设计的工作方式。

## 为什么是 Weir

普通 AI 助手容易「聊着聊着就偏了」：任务做到一半停下等你催、上下文一满就丢三落四、什么活都用同一个模型硬扛。Weir 针对这些顽疾做了一整套设计——从意图识别、任务编排到工程执行，每一环都有明确的纪律与验收。

## 核心能力

### 听懂与统筹

- **听懂你的话**：一句「深度工作」「仔细研究一下」，助手自动进入对应的工作模式；说「think」，它会用更深的推理档位回答你。开启语义分类后，即使不说关键词也能听懂意图（分类失败自动按未命中处理，绝不误事）。
- **总指挥坐镇**：简单的活直接干，复杂的活拆给专长子代理；能并行的绝不排队，每个子任务都有明确的交付标准和验收。
- **专业的事交给专业的模型**：九种任务类别（快速问答、深度分析、架构咨询……）与三个只读研究代理（代码检索 / 文档调研 / 架构建议）各自绑定最合适的模型链，主模型不可用时自动降级到备选，绝不悄悄乱换。每条链都能在设置页可视化配置，不需要的类别一键停用。

### 跑到底，不烂尾

- **不催不停**：任务清单没做完，助手会自己接着干；你随时喊停它就停（你的打断永远优先）；供应商抖动时自动退避重试，连续失败如实报告，绝不假装没发生。
- **长任务不丢上下文**：上下文将满时，助手会被提醒在合适的时机自行整理记忆；逼近极限时自动压缩，绝不让重要信息被生硬截断。
- **后台任务不刷屏**：耗时的委派放后台跑，完成时只收到一条简短通知，细节随时调取。关联任务可显式分组——同组全部落定后收到一条完成信号，异常自动续推恢复；需要反复打磨的活可选用续聊形态，子任务记得之前的上下文，重启应用也不丢。
- **人不在屏幕前也不耽误**：助手需要审批、回答问题，或长活跑完时，会以系统通知提醒你（正看着窗口时默认不打扰）。该能力对整个 profile 生效，不限于 Weir 会话。

### 工程级的执行工具

- **编辑更稳更省**：文件读取自带锚点，编辑逐锚校验、一处对不上就整体拒绝——改得准、不毁文件、还省 token，每次编辑以逐行着色的 diff 面板呈现。
- **语义答案随手可得**：开启 LSP 能力后，「跳到定义」「谁在引用这个函数」由语言服务器给出真实语义回答；跨文件语义重命名经版本护栏安全落盘。设置里可一键安装缺失的语言服务器（13 种语言社区目录）。
- **发现不再白费**：子代理挖到的昂贵知识（哪个包管什么、验证过的硬约束、走不通的路）写进会话「黑板」，同一事实不挖第二遍；右侧栏黑板面板可查看、搜索、亲手编辑，值得长期保留的条目经你裁决后晋升进持久文档。详见 [会话黑板](docs/features/blackboard.md)。
- **改动互不打架**：需要隔离的改动放进独立 worktree 车道——每条车道有自己的分支和目录，合并前你在卡片上确认改了什么、要不要合；合并后由你决定保留还是清理。`/worktree` 命令和右侧栏面板让你随时看清每条车道的状态。
- **多会话不再互相覆盖（实验）**：开启「编辑锁」后，同一项目里的多个会话改文件前都要先持有该文件——别人正在改的文件你改不了，可以请求对方转交。详见 [编辑锁](docs/features/edit-lock.md)。

## 安装与启用

1. 在 Harness 会话中由 `plugin_manager` 以本仓库 `plugins/weir-harness` 目录安装 bundle（link 安装，随源码更新）。
2. 打开 Web GUI 的预设选择器，选择 **Weir** 创建新会话。想开发、调试或实验 DeepSeek Harness 本身时，改用 **Weir 创造模式**——同一套 Weir 工作方式，额外带上 DSH 创造模式的运行时检查工具与开发技能。详见 [预设打包](docs/features/preset-packaging.md)。
3. 其他预设（如 standard）完全不受影响——Weir 的一切只在它自己的会话里生效（唯一例外是系统通知，它挂在 profile 层、覆盖所有会话，可在设置页关闭）。

## 配置

打开全局设置的 **Weir 设置页**，一站式调整：意图分类器档位、九种类别与三个只读研究代理的模型链、续推与退避上限、上下文压力阈值、锚点编辑开关、只读 shell 白名单等。页面按卡片分区组织，细调参数收在各自总开关之下即时显隐；多数改动**在同一进程内即刻生效**，少数需重启的选项带常驻「需重启」标记，保存后弹窗点名提醒。

## 内置工作技能

Weir 自带十项开箱即用的工作技能，意图命中时自动加载，也可以随时手动调用：

| 技能 | 一句话说明 |
|---|---|
| `deep-work` | 证据驱动的端到端完成模式：不拿「看起来对了」当完成 |
| `research` | 深度研究：并行检索代码、文档与网络，产出带引用的综述 |
| `review-work` | 完工把关：先亲自在实际界面上验证，再从目标覆盖、代码质量、安全性审计 |
| `debugging` | 假设驱动的调试：先复现、排序假设、用最便宜的判别实验定位根因 |
| `git-master` | git 全科医生：原子提交、rebase、squash、blame、bisect、reflog、历史考古 |
| `refactor` | 重构向导：用正确的分解方式做重构、清理与重组 |
| `programming` | 语言实践纪律：Python/Rust/TypeScript/Go 的严格现代写法（含分语言参考） |
| `remove-ai-slops` | 清除 AI 代码异味：在回归测试保护下给分支改动「去腻」 |
| `work-with-pr` | PR 全生命周期：独立 worktree 实现、证据绑定的手工验证、可读性优先的 PR 描述 |
| `remove-deadcode` | 死代码清理：安全验证 + 原子提交，删掉无人使用的代码 |

### 会话能力管理

- Weir 会话只显示**已启用**的技能与 MCP server——未选中的第三方能力不再自动出现，选择由右侧栏 **Capabilities 面板**显式管理（技能按来源分组勾选、MCP 按会话启停）。详见 [会话能力管理器](docs/features/session-capability-manager.md)。
- 能力集合可保存为**预设**并导入/导出（限定到本工作区），还可存为「工作区新会话默认值」。
- 已安装的第三方技能可定期**检查更新**：只读检查、改动需你确认才发布，已接受的内容在来源更新后仍按原样可用。详见 [Skill 分发](docs/features/skill-distribution.md)。
- 打开历史会话时技能菜单先短暂为空（冷会话不猜测、先空后收敛），自动恢复完成后即显示该会话的已选集合。
