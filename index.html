协作有章法，交付有依据

BUILT FOR COLLABORATION

用共享知识、写入保护和任务监督，为多代理协作建立清晰的边界。

以下为功能流程示意

01 / 共享知识会话黑板

发现一次
共同受益

把代码布局、关键约束和已排除的方案留在会话黑板，让后续代理接着已有发现工作。

  • 共享发现，减少重复探索。
  • 延续发现，重启保留；Fork 会话继承独立快照。
  • 由你筛选，将有价值的知识保存为跨会话文档。
了解工作原理 ↗
02 / 可靠编辑默认开启

明确归属
减少冲突

编辑锁为文件分配写入权，让并行会话在修改前协调，减少相互覆盖。

  • 按文件保护，跨会话协调写入。
  • 支持转交，由当前持有者处理请求。
  • 及时释放，回合结束时释放或限时保留。

保护范围为宿主编辑工具，不包含 shell 和外部编辑器。

了解工作原理 ↗
03 / 隔离开发Worktree 车道

各自推进
有序汇合

每条车道拥有独立分支与目录，让并行改动保持清晰，检查后再合并。

  • 独立工作区，隔离每个任务的改动。
  • 合并前检查，预检冲突并支持验证命令。
  • 可配置授权，按工作习惯选择合并策略。
了解工作原理 ↗
04 / 任务监督受监督任务组

并行执行
进展可循

将相关任务组成受监督的代理组，集中跟进进度、处理阻塞并汇总结果。

  • 明确状态，成员报告完成或阻塞。
  • 及时回报，成员结果随完成送达，组收尾时统一通知。
  • 持续跟进，支持恢复子任务与重启后的状态重建。

  1. 01

    打开插件管理

    在 DeepSeek Harness 桌面应用中，进入插件管理面板，点击「添加插件」。

  2. 02

    输入包名并安装

    weir-harness@1.2.2
  3. 03

    重启 DSH

    安装完成后，退出并重新打开 DeepSeek Harness（DSH），再继续下一步。

  4. 04

    选择 Weir，新建会话

    重启后，在 Web GUI 的预设选择器中选择 Weir，新建会话即可使用。

使用终端安装
dsh plugin --profile <profile> add weir-harness@1.2.2

将 <profile> 替换为你的 Harness profile 名称。安装完成后请重启 DSH，再选择 Weir 新建会话。

全局设置中，「Weir」管理通用行为，「Weir 模型路由」配置委派模型与备选链。

你可能还想了解

FAQ
Weir 是独立应用吗？

Weir 是运行在 DeepSeek Harness 桌面应用上的预设。安装后重启 DSH，再选择 Weir 新建会话；其他预设不受影响，系统通知设置对整个 profile 生效。

需要额外配置模型吗？

安装并重启 DSH 后可以使用默认配置。也可以在「全局设置 → Weir 模型路由」中，为不同任务类别设置模型、推理等级与备选链。

如何隔离并行任务的改动？

Worktree 车道提供独立分支与目录。按需开启 Worktree 模式可要求所有写入经过车道；合并授权方式可在设置中调整。

编辑锁默认开启吗？

编辑锁现已稳定并默认开启；显式关闭过的设置会保留。它保护宿主编辑工具的写入，shell 和外部编辑器不在保护范围。开关变更需重启生效。
